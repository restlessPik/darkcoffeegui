# Dark Coffee GUI
This resourcepack reimagines Minecraft's Graphical User Interface with a warm, cozy and dark style, taking vanilla's more simple design and transforming it into something fancier and more visually appealing, perfect for those late night sessions.

This page is mainly for issues, idk how Github works :p
## Compatibility
Made for versions most versions of Minecraft, with 5 main versions: 1.8, 1.12.2, 1.13-1.16, 1.20.1 and the latest version available. Though the resourcepack supports all these versions the main support will come for latest versions of Minecraft, I'm the only one maintaining this pack and I don't have that much time.

From version 1.16 and below, the colored text will be white and only work in English US. There are no plans to implement more language support at the moment, but if I have time I will try to look into it.
